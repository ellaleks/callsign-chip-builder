# Конструктор фишки-визитки

Откройте сайт, введите свой позывной и контакты, выберите размер и нажмите **Update chip**. Затем **Download print kit** скачает три цветных STL и сборку 3MF. **3MF only** скачивает только сборку.

**Plain text** — минимальный QR с обычным текстом. **Contact card** — vCard 3.0: поддерживающий сканер может предложить сохранить контакт. Окончательное поведение зависит от телефона. **ECC L** даёт менее плотный код; **M** добавляет избыточность.

Под предпросмотром показан реальный размер клетки QR. При слишком мелких клетках увеличьте диаметр, уменьшите содержимое или выберите более тонкое сопло. Это расчёт геометрии, а не гарантия считывания пластика.

Все вычисления выполняются в браузере. Контактные данные не отправляются на сервер. Они входят в скачанные файлы: не выкладывайте такой архив публично по ошибке. Публичный пример использует только вымышленные данные.

Для локального запуска распакуйте исходники, откройте терминал в папке и выполните `python -m http.server 8765 --bind 127.0.0.1`. Откройте `http://127.0.0.1:8765`. Прямое открытие index.html через file:// не подходит для Web Worker/WASM.

Для OrcaSlicer используйте свой рабочий профиль принтера. Импортируйте 3MF как модель; раскройте объект и назначьте частям цвета. Либо загрузите одновременно три STL как один объект с несколькими частями. Печатать QR вверх, лицевой стороной на стол, без переворота и поддержек. Пробный вариант: первый слой 0,20 мм, остальные 0,10 мм. Сохраните проверенные настройки продувки при смене филамента.

Проверки: четыре набора параметров, замкнутые экспортированные STL, отсутствие объёмных пересечений цветов и точное декодирование QR с геометрии. Физическая печать и считывание с пластика не проверены. Перед серией напечатайте и проверьте один образец.

В трёх тестах OpenCV прочитал QR со всей задней стороны; в тесте Ø40 мм / QR версии 1 — только после выделения белого поля QR из изображения. Это ограничение детектора отмечено в VALIDATION.json. Толщина задаётся с шагом 0,1 мм.

Исходники и инструкция публикации на GitHub Pages: README.md. Подготовленный текст Printables: printables/LISTING.md.
